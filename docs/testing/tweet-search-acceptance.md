## 10 万条合成数据基准

测试只使用 `generate_series(1, 100000)` 生成的合成 Tweet，不读取真实归档内容。环境为本地 Docker PostgreSQL 16；每组查询预热 3 次，再记录 20 次 service 层完整分页查询（包含结果、总数和附属数据）的耗时。

| 场景 | 匹配数 | 中位数 | P95 | 最大值 |
| --- | ---: | ---: | ---: | ---: |
| 英文关键词 `orbital mechanics` | 10 | 12.54 ms | 12.94 ms | 13.27 ms |
| 中文关键词 `量子纠缠` | 6 | 12.19 ms | 12.77 ms | 14.46 ms |
| 拼写近似 `orbital mechanix` | 10 | 12.84 ms | 14.13 ms | 19.87 ms |
| 无关键词，已校验状态，最新优先 | 95,000 | 57.47 ms | 60.98 ms | 64.65 ms |

首轮实现使用 `strpos` 做字面子串判断，三类关键词查询中位数约 860–930 ms。验收据此改为带显式转义的 `LIKE` 子串模式，使 `gin_trgm_ops` 索引可参与查询；上表为修正后的复测结果。

可复现步骤：

1. 在隔离数据库迁移到 head。
2. 用 `generate_series` 插入 10 万条合成 Tweet，并对 `tweets` 与 `tweet_search_documents` 执行 `ANALYZE`。
3. 设置隔离 `DATABASE_URL` 和 `PYTHONPATH=/app`，运行 `/app/tests/benchmark_tweet_search.py`。
4. 验收完成后删除隔离数据库。

该脚本是人工性能验收入口，不属于单元测试发现模式，不应在日常测试套件中自动运行。

## WebUI 联调

- 桌面视口确认独立搜索页、结果卡、筛选面板、状态文案和分页。
- 390 × 844 窄屏确认侧栏隐藏、筛选按钮与 Sheet 内全部条件可用。
- 确认关键词、筛选、排序和分页 offset 写入 URL，刷新后关键词和筛选保持。
- 日期按浏览器本地自然日换算为 UTC 查询边界；夏令时变化地区的单次搜索使用发起搜索时的浏览器偏移量。
- 用单条临时合成 Tweet 验证正文高亮、标签、合集、备注摘要、详情链接和全屏媒体预览；完成后已精确清理该记录。
- Playwright 回归验证媒体调试模式会同时遮罩关键词、作者、正文、标签、合集与私人备注摘要，并验证关闭全屏预览后列表视频从预览进度恢复播放。
- 页面控制台未发现应用自身错误；浏览器扩展产生的既有报错不计入应用验收。
- 搜索关键词会写入本地页面 URL 和浏览器历史；媒体调试模式会遮罩搜索框及结果整理信息，但地址栏仍可能显示关键词，录屏或共享屏幕前应清除敏感查询。
